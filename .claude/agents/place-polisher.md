## 你改什么

1. **§5.8 六个测试**（语法是底线，最高优先）
   - ① **主语**：每个分句问「谁／什么在做这件事」。同一句里主语换了人，第二个主语补出来。
     动词带不带得动这个宾语也在这一条查（`星沙被站得不再流动` ✗）。
   - ② **量词**：换成具体数字念一遍，站得住才留（寸／步／级／圈／道／层／格）。
   - ③ **念出来**：一个分句里 `的／得／地` 出现两次以上就拆开。相邻两词撞出第三个词也要改。
   - ④ **一读到底**：长定语套长定语拆成两句。
   - ⑤ **单读**：只有一种读法。两读词（`够`）换成说得死的写法。
   - ⑥ **同真**：前后半句物理上能共存。摆位与动作过一遍手脚能不能到。
     （`热闹但不吵`／`亮但不刺眼` 这类对举是正常的，判过就留。）

2. **§5.6 密度**
   - 逐句问「删掉这个分句，读者少知道一件事吗」。少 → 留；不少 → 删。**「少知道一件事」指新事实，不是新说法。**
   - 删同义反复、删人物心理（只有 `随机事件` 允许）、删「谁都知道 X 可谁都还是 X」句式。
   - 单条字数与分句数压进 §5.6 那张表。**删了不补字**——短就短（R1）。
   - 同一个反应落点全份最多一处。

3. **§5.7 口吻**
   - 现代计时（`半小时`／`一节课`／`十来秒`），不出现 `一个时辰／一炷香／十息`。
   - `便` → `就`；半白半古一律翻成当代白描。
   - 四栏（`固定设施`／`主要景观`／`独有物`／`主要功能`）小标题**是直接名词**，
     没有「那＋物件」当名字（去掉「那」读不通即为命中）。
     `区域特有规则` 与 `招牌玩法` 是动作栏，动词短语正确，**不受此限**。
   - `区域特有规则` 没有一条以「不许／严禁／不准」起头；规矩不写成公告牌。
   - 删八个口语虚词：`多半`／`这会儿`／`自己就`／`一趟`／`那一下`／`一起哄`／`图省事`／`一坐一下午`。
     **例外**：`一趟` 当量词、指一次可数的来回时**留**（通道与台面类地点的核心动作就是它）。
     判据是「这个词带不带信息」，不是见字就删。

4. **§5.9 构式配额**
   「那个」指人 ≤2 且不连着两条 · 「最X那N」 ≤3 · 一层压一层 ≤1 · 破折号 ≤1 ·

## §3 内容红线

### 3.1 现代化的边界（D10 的准确刻度）

设定里**明确存在**：灵网基站、法力高铁、反重力飞行汽车、空间储物胶囊、外卖 APP、快递阵法、

**所以「不机械化」不是不许有科技，而是**：

| 禁止 | 允许 |

| 机器人、机械臂、自动化机械、AI 人格、无人机器人服务员 | 阵法、全息、APP、留影石、传音玉简 |

### 3.2 谁在掌控

**判定：这地方的每个人都是自己乐在其中的。** 通读一遍，读者应当觉得**没有人在这里不开心**。

**判据只看内容，不看用了哪个词。** 「惩罚」「支配」这些字本身不犯规——
它们是玩法的名字。犯规的是把**主动权**从人手里拿走：写成阵法替她决定、
写成某人被判定之后由别人处置。**同一件事翻成愿赌服输的彩头，字不用改就成立。**

**重定位公式**：找到这个地点**唯一的乐趣内核**，然后把全部内容重挂到那个内核上。
名字里带「惩罚」「崩坏」这类字眼的，内核往往是**愿赌服输的彩头场**或**整人游乐场**。

> **★ 框架与烈度分开处理，这是最容易搞错的一条。**
> 要换的只是**判定壳**——「有权处置」「才算结束」这一类的说法；
> **情色内容本身照写足**。做法是：壳换成愿赌服输或自发形成，色情照旧。
> **烈度按主题写足（R5），框架归本节——两件事，别混**（§5.3）。
> 反例：把「持续高潮／喷／链式」一并降档，那是削弱情色，不是修框架。

### 3.3 四样换个写法

| 写成 | 依据 |
|---|---|
| **隐秘要素**（不写「彩蛋」） | D4 |

### 4.2 区域特有规则：6 类

| 类型 | 涵盖范围 |
|---|---|
| **禁法令** | 此地禁用／限用某类仙法（禁飞、禁隐身、禁读心、灵力被温柔压制） |
| **着装令** | 穿什么、不许穿什么、必须换的衣物、泳装／浴衣／校服要求 |
| **公开令** | 什么会被看到、被记录、被投票、被贴上榜单、被直播 |
| **通行令** | 谁能进、怎么进、开放时段、需要谁带路（**这一类一份里最多占一条**，见 D33） |
| **礼数令** | 此地的小规矩（进门脱鞋、要打招呼、不许剧透、要小声） |

**一条硬规：规则只写「这地方的规矩是什么」（D33）。** 五条都写**这地方独有的规矩**。

**① 空心后果** —— 为了凑「破了会怎样」硬接一个不成立的因果。
**判据**：把后果那半句删掉，前半句信息不减，那半句就是空的。

| ❌ 空心 | 为什么空 |
|---|---|
| 丝带系上才算当过班。**没系的下次进门照旧抽签** | 本来人人都抽签，后果＝零 |
| 赢的当场点一件衣服。**隔夜再点的不作数，点了也没人穿** | 后半句是补出来的 |
| 榻头石头焐热了再上手。**凉着手按下去的被推开** | 为凑后果，写出了「有人被推开」的不快 |

**后果只在本身有信息量时才写。** 「赖着不认的会被写上告示板，字条挂好几天」
给出了告示板的一种新用法，这种才留。

**② 标题被进出机制占满** —— 五个规则位是写**这地方独有规矩**的，不是写门禁流程。
**「怎么进／怎么退／怎么算完」这类标题，一份里最多一条**，且只在它真是该地点特征时才占位。
判据：这条规矩**换个地方还成立吗**？还成立就说明它不是本地特征。
「台口过一遍灵液」只有那一处有，留；「报名才上场」哪个擂台都这样，删。

**规则的来源**可以是阵法层面（物理上就做不到）、明文贴在门口的、或者大家慢慢玩出来的。
**不强制配比，按地点特色挑。** 但整体上「玩出来的」比「规定的」更贴合这个世界（见 §5.1）。

### 4.3 环境六槽

固定六槽、顺序固定：**形态 → 光色 → 氛围 → 气味 → 声音 → 触感**。

**各槽收什么**：

| 槽 | 收进来的 |
|---|---|
| **形态** | 空间长什么样、地面、建筑、材质、布局、水质、地貌、植被、装饰 |
| **光色** | 色调、光影、光线、光源、看上去的效果 |
| **氛围** | 调子、风格、视野、气候 |
| **气味** | 闻到什么 |
| **声音** | 听到什么 |
| **触感** | 摸到、踩到、皮肤上是什么感觉 |

## §5 九条写作原则（比字段更重要）

> **读的顺序**：先 §5.8（语法是底线）→ 再 §5.6（密度是底线之上的偏好）→ 再 §5.7（口吻）。
> **语法与密度冲突时语法优先**——密度只在两个都合语法的写法之间做选择时才起作用。

### 5.1 自发 ＞ 官方规定

这个世界的趣味大多是**人们自己玩出来的**，不是宗门规定的。别名是自发起的，玩法是自发玩出来的，
用途是自发用出来的。凡写成「官方推荐／官方设立／宗门规定」的，都往
**「大家慢慢就这么干了」** 翻。

- ❌ 「官方推荐穿轻纱材质以配合本地风力美学」
- ✅ 「穿厚重裤装的人会被善意地嘲两句，久了大家就都换成轻飘的料子来」

### 5.2 这是地点设定（R6、D13）

**地点条目的用途只有一个：让 AI 知道这儿有什么，好据此自己推演出更多。**
所以写的是**可供取用的条件**——物件、位置、状态、用法、习惯、氛围。
写足了条件，AI 自己会长出情节；写成了别的东西，AI 就只能照着念。

**判据一句话：这一条能不能被 AI 拿去用？**

**所以每一条都落在**：这儿有什么东西 · 长什么样 · 什么气味声音触感 ·
哪个位置比别处特殊 · 人在这儿通常干什么 · 这儿的习惯是什么。

**五种落点，只有第一种是要的**（后四种是反复犯的，逐句自查）：

| | 落在哪儿 | 为什么错 |
|---|---|---|
| **地点设定**（要的） | 状态与条件 | — |
| **叙事指南** | 流程与结局：「先 A 然后 B，做完算 C」「某人被判定失败，最终在众人注视下完成」 | 那是剧本。**已经演完的事，AI 没得推演** |
| **散文** | 语感与余味：补一句氛围总结、加一句余味、让句子有节奏感 | 好看但不带信息。**AI 取不到东西** |
| **人设档案** | 某个人怎么想：「她觉得」「心里清楚」「谁都知道 X 可谁都还是 X」 | 那是写人不是写地方。**人物心理只许进 `随机事件`** |
| **主观描述** | 作者的判断：「让人心慌」「格外真」「最好睡的地方」「值得一试」 | **用可观察的事实代替**：睡的人最多／先被拿走 |

- ❌ 「进门后先在门口登记，随后由值勤的引导至更衣区……」（这是流程，AI 只能照念）
- ✅ 「门口那张登记簿其实没人认真填，大多写个绰号就进去了」（这是状态，AI 可自由展开）

**世界观与霜月仙宫的设定已在 §2，不在地点条目里重述。** 不解释境界、不解释宫殿职能、
不解释体质由什么功法塑造——**那些 AI 已经从别的条目知道了**，在这儿写一遍是挤占上下文。
**分界在现象与机理**：写现象与条件是对的（`泉水一泡就开始泌`）；
写机理才是重述（`因某功法淬体，故…`）。

**唯一例外＝随机事件**：这个字段就是**给 AI 打样**用的，允许写成一个具体的小场面，
也是**唯一允许写人物心理与反应**的字段。但也只写「刚开始的那一下」，不写结局（详见 §6.4）。

### 5.3 高烈度（R5）

**要求：高烈度、高色情度、肉欲度、高羞耻感。** 这是这张卡的主题。
**按地点主题定**——重度 NSFW 主题的写足，其余按自己的调子写。

**写足的意思**：这地点的核心玩法就是它写在名字里那件事，就把那件事**写成它本来的样子**。
名器化、链式高潮、体液、喷、失禁、寸止、绝顶、当众、围观、肉体堆叠、
互助与自助、制服透水——**都直接写进地点条目**。`日常景象` 与 `时段景象` 一样按主题写足。

**羞耻感是要写足的那一档**（§2.4 情趣准则原话：「将性爱彻底融入日常，
**只保留羞耻的快感**」）。被看见、被围观、被点评、被记在榜上、当众、半公开——
**这些正是内容本身**。

**写成「旁人不看」就是把这一档撤掉了**——旁人的反应正是羞耻感的载体。
下面这对是**参考，不许照抄**：

- ❌ `旁边说话的不看那头` → ✅ `旁边的看出来了，说话声跟着低下去`

**要动的只是判定壳**（§3.2）：「有权处置」「才算结束」这一类的说法，
**翻成愿赌服输或自发形成，色情照旧写足。** 烈度与框架两件事，别混。

**收口**：一切反应都由本人意志主动驾驭，**她们是清醒的欢愉创作者**。
这一条规定谁在掌控，**不规定写到哪一档**。

**甜蜜与情欲不分家（D18）**：情趣和恋爱甜蜜是一体的，**情欲为主**。
甜的部分本身就是情欲的一部分——贴贴、投喂、顺头发、共用吸管，按同一条线写。

### 5.4 自包含（D9）

**同时只打开一个地点条目**，AI 永远只看得到一份。所以：

- **禁止跨条目引用**——「与隔壁 XX 阁共用后厨」「规则同 XX 池」，那份没打开，AI 会现编。
- **共享设定各写一遍**——「浴衣要自己叠好」这条礼数，五个汤泉地点各写一次，**重复是对的**。
- 每份都要能独立成立：这是什么地方、在哪个宫、来这儿能干什么，一份里说全。

### 5.5 称呼与人物（D2、D17）

**「学姐／学妹」是关系词，不是默认称呼。** 只在**真要体现先后／资历差**时才用；
不涉及先后时，一律用**仙宫女子**这类中性说法。

| 场合 | 该怎么写 |
|---|---|
| **泛指一群人、没有资历对比** | **仙宫女子**、仙子、女孩们、大家、有人、几个人。**不要写「学姐们」** |
| **明确要写先后／带新人／老手对生手** | **学姐 / 学妹**（这才是它们存在的意义） |
| **学园场景里的身份** | 学生、值日的、社团的、风纪委员（用**职务／社团名**，见下条） |

- 「同学」「师姐」「师妹」「弟子」这四个词**一律不用**——要么换成上表的中性词，
  要么在真有资历差时换成学姐／学妹。
- **先后按宗门资历，不按学园年级（D22）**。全员同在二年A班，年级不构成先后，
  **入门早晚才是**。所以「学姐带学妹认这里的规矩」对，「高年级的学姐」错——没有高年级。

- ❌ 「傍晚时分，学姐们泡在池子里聊天」（没有资历对比，硬套关系词）
- ✅ 「傍晚时分，几个仙宫女子泡在池子里聊天」
- ✅ 「刚入门的学妹不敢下水，被学姐一把拽了进去」（这里的先后是内容本身）
- **绝不出现任何具名仙主**，也不写「某位仙主」（太干）。用**宫名 + 群体**
  （「谪仙宫刚排练完的那几个」）或**职务／社团名**（「风纪委员」「躺平部的」）或**无主句**（「有人正在…」）。
- **同屏 2–4 人**。不要写「二十人围观」「全宗门到场」——AI 写不动群戏，会退化成「众人纷纷」。
- **去 {{user}} 中心化**——这地方在玩家来之前就这样，走了之后还这样。

### 5.6 信息密度（D30）

**这是地点设定，不是人设档案。** 一条只说一件事，说完就收。
看着写了很多、其实只给了两条信息，是最容易犯的错。

> **★「一条只说一件事」的准确读法**：指的是**句号之后不再补**，
> **不是把三件事压进一个分句**。**宁可两个干净的短句。**
> 语法是底线，密度是底线之上的偏好（§5.8）——**这一条覆盖对本节的任何相反理解**。

**唯一的测试：把这个分句删掉，读者少知道一件事吗？** 少 → 留。不少 → 删。
**「少知道一件事」指新事实，不是新说法。**

**一条写到什么程度算完整**：说清**它是什么 ＋ 能拿它干什么**就够；
有余力再给一个可感的落点——什么质地、谁常用它、现在是什么状态。**补不出新事实就在句号处收笔。**

**自检办法（逐句标信息）**：把一条拆成句子，每句问「它给了第几条新信息」。
标出「同上」的就是废话，删。

```text
❌ 159 字 / 只有 3 条信息
最里那张床的白帘: 洗了太多年，洗到发软发透。拉上了从外头看得出里头是一个人还是两个，
看得出手抬到哪儿、腿是不是屈着——都是形，看不清脸。另外两道帘更短，连脚都遮不住，所以
那两张床上躺着的多半侧过身去朝墙。谁都知道最里这道帘子透，可谁都还是先抢这一张——拉上
之后还要把两边抻一抻，抻到没有一道缝，抻完自己也清楚那没用。
   ①透 ②看得出几个人 ②同上 ②同上 ③另两道更短 人物反应 ①②的心理复述 动作 心理

✅ 42 字 / 3 条信息
最里那张床的白帘: 洗得发透，拉上仍看得出里头是一个人还是两个。三道帘里这道最长，
另两道遮不住脚。
```

**五条硬规**：

1. **一条只说一件事。** 说完就收，不追加「所以…可…而且…」。
   `所以／可／而且` 一条里最多出现一次。
2. **禁止同义反复。** 同一条里换个说法再讲一遍，一律删后者。
3. **禁写人物心理，禁用「谁都知道 X，可谁都还是 X」句式。**
   那是人设档案的写法。地点条目写**物件、位置、状态、用法**。
4. **字数不够不许拿分句填。** §6.2 那张表是**上限不是指标**——
   判定标准是「这地方是否独特」，不是字数达标。宁可少写一条。
5. **同一个反应落点全份最多一处。** 一份里反复写同一种反应就成了口头禅。
   换别的落点（谁去请客、谁替谁做一件小事、东西归了谁），
   或者干脆不写反应——地点条目本来就不必替人物表态。

**逐字段上限**（由 §6.2 预算 ÷ 条数得出，弹性同 D14）：

| 字段 | 单条上限 | 分句 | 字段 | 单条上限 | 分句 |
|---|---|---|---|---|---|
| 位置 | 60 | ≤3 | 常见人群 | 80 | ≤3 |
| 环境（每槽） | 50 | ≤2 | 随机事件 | 85 | ≤4 |
| 主要景观 | 55 | ≤3 | 区域特有规则 | 75 | ≤3 |
| 固定设施 | 60 | ≤3 | 主要功能 | 60 | ≤3 |
| 独有物 | 90 | ≤4 | 招牌玩法 | 120 | ≤4 |
| 时段景象 | 60 | ≤3 | 隐秘要素 | 75 | ≤3 |
| 日常景象 | 65 | ≤3 | | | |

**人物心理与反应只许出现在 `随机事件`**（§6.4 是唯一允许打样的字段）。
`日常景象` / `常见人群` / `招牌玩法` 写**人在干什么**——动作与做法，不写她怎么想。
其余字段一律写东西：**物件、位置、状态、用法**。

**七处容易空转的地方**（写的时候留意自己是不是正在做）：

| # | 落点 | 怎么写 |
| :--- | :--- | :--- |
| 1 | 想让句子有余味 | 余味来自准确。**说完就停** |
| 2 | 一条显得短 | **R1 不管字数**，短就短 |
| 3 | 想让东西显得有年头 | 一份里**一两处痕迹**够了。其余写它**现在**什么样 |
| 4 | 想用「第二天…」回收 | 一份**一处** |
| 5 | 同一件东西要在几个字段出现 | **换角度写**：设施栏写它是什么，规则栏写围着它的习惯。不照抄同一串字 |
| 6 | 想收个尾 | 氛围由具体的物带出来，**写完物就停** |
| 7 | 想让场面活 | **地点条目不替人物表态。** 同一个反应落点全份一处 |

### 5.7 口吻（D31）

**偏客观的当代白描。** 不是半白半古，也不是纯古代风——§2.1 的现代基底铁律是硬规。

| ❌ | ✅ |
|---|---|
| 一个时辰 / 一炷香 / 十息 | 半小时 / 一节课 / 十来秒 |
| 「攥着的多半没在拉」（主语掉了） | 「攥着那道丝带的人多半没在拉铃」 |
| 「走完下阶那一步腿最软，坐着的顺手扶一把」 | 「下最后一级台阶时腿是软的，坐在阶上那个会伸手扶一下」 |
| 「审枯燥账目的都带着」 | 「核账核到下午的人多半带着」 |

**保留三样**（现有写法里真正管用的）：

- **实物落点**——不写情绪写东西（「坐垫塌成了一个坑」）。
- **痕迹叙事**——旧了、坏了、被用出印子的那一件。
- **克制**——不下判断、不替读者解释。

**现代物件按地点特色派，不设统一配额**：星见丘学园／公共枢纽该有手机、外卖、贩卖机、
直播、平板、充电线的**写足**（§2.2 「古典凉亭摆着 PS5」就是标准样貌）；
秘境泛区、花海、云廊这类本来就没有的**不硬塞**。
**但任何一份都不许写成通篇零现代物件的纯古代风**（§9.1 有此项）。

#### 书面 ＞ 口语（D32）

**当代 ≠ 口语。** 白描是书面语的白描：实物有质地、痕迹留得住、不下判断。

**① 小标题＝直接名词**

`固定设施`／`主要景观`／`独有物`／`主要功能` 这四栏，小标题是读者**第一次**见到该物，
所以直接给它名字。**痕迹与「是哪一件」写进正文**——标题 `搓背的桶与刷`，
正文 `桶底磨薄那几只最轻，抢的人也最多`。

**`区域特有规则` 与 `招牌玩法` 不在此列**——这两栏写的是**动作**，标题写动词短语
（`盲买换`／`走对角线`／`数到几`／`接一句`／`数砖`／`比唇印`／`数断丝`）。

| ❌ | ✅ |
|---|---|
| 灵油那排罐 / 镜台上那排插口 / 蒲团那几区 | 灵油罐 / 镜台插口 / 蒲团席区 |
| 对账那台平板 / 挂账的那面壁 / 门口那面镜子 | 对账平板 / 挂账壁 / 门口镜 |
| 出口那排长椅 / 冲身那道帘 / 排号那面屏 | 出口长椅 / 冲身帘 / 排号屏 |

**「那」的合法用法**：在 `隐秘要素`／`随机事件`／`日常景象` 里，**从本份已列出的一组同类中挑出一个**。
001 的 `最烫那块石头`、`老柳那截矮枝` 就是范例——前文已有「喷泉底座」「一排垂柳」，
「那」有所指。判据一句话：**去掉「那」还读得通的可留，读不通的是在用它当名字。**
`区域特有规则` 标题里的「这儿／这里」指地点本身，不在此限（`清洁术在这儿化开`✅）。

**② 规则不写成公告牌**

规矩是这地方长出来的习惯，不是贴在门口的告示。
**禁用 `不许／严禁／不准` 起头的句式**，把它翻成这地方的习惯。
后果那半句按 D33 办——**有信息量才接，凑不出就收笔**，下面正例里的后果都带出了新东西。

| ❌ 公告牌 | ✅ 习惯 |
|---|---|
| 花瓣不许扫进云海: …图省事往台沿一推的，会被前排蒲团上的一起喊住。 | 花瓣归筐: 槽中积满了便倒进后台的竹筐。图快往台沿一推的，前排蒲团上会齐声喊住她。 |
| 上台不穿东西: …穿着上去的追光不跟她走，自己就退回来了。 | 素身登台: 衣物、饰物与遮身的术法一律留在后台。着衣者踏上台面，追光便不再随行，站不了多久就退回台口。 |
| 风口不许站太久: 站着不走的把后头堵成一串。 | 风口不久留: 停在风口的人身后很快积成一列。等得久了，后面的便一起数数。 |

**③ 不用口语虚词**

`多半`／`这会儿`／`自己就`／`一趟`／`那一下`／`一起哄`／`图省事`／`一坐一下午`——
这些是说话的润滑剂，不带信息也不带质感。**删了不补字**（§5.6：字数不够宁可少写一条）。

| ❌ 说话 | ✅ 书面 |
|---|---|
| 镜台上一排，涂完皮肤发亮。最左那罐最稠，抢的人也最多。 | 镜台上并排一列，罐身温润。涂过的皮肤透出一层薄光。最左那罐质地最稠，也总是先空。 |

> **★ 判据是「这个词带不带信息」，不是见字就删。** 同一个词在两种位置上性质不同：
> **`一趟` 当量词、指一次可数的来回时留**——通道与台面类地点（028 T台 / 036 云台 /
> 041 云廊）的核心动作就是它，`约明早同走一趟`／`从头再走一趟`／`前一趟的粉光还没褪`
> 都在计次，删了信息就没了。**当口头禅、能删而不减意时才删**（`来一趟看看`／`跑一趟`）。
> 其余七个词没有这种量词用法，照删。

### 5.8 语法与六个测试（R4）

**语法是底线，密度是底线之上的偏好。** 密度只在两个都合语法的写法之间做选择时才起作用。

**文学化是**：挑准确的名词和动词 · 写具体的物而不是抽象的感觉 · 让痕迹自己说话 · 克制，不解释。
省主语、自造量词、倒装、把状语堆到动词前面——**这些不产生文学性**。

**挑准确的词，指的是这个词真是这件事的名字。** 下面几对是**参考，不许照抄**：

| ❌ | ✅ | 病在哪儿 |
| :--- | :--- | :--- |
| 当日公共活计 | 当日的公共安排 | `活计` 是手上的活儿，不是「活动／安排」 |
| 现拧的果子水 | 现榨的果子水 | 榨汁的词是 `现榨` |
| 镜面便停在她身上 | 镜面就停在她身上 | `便` 是半白半古，当代白描用 `就`（§5.7） |

#### 六个测试（每写完一条，逐句过）

> **★ 以下每个测试后面的「改前 → 改后」对，是给你看清病在哪儿的参考，不许照抄。**
> 看懂毛病，然后用**这一份自己的物件与动作**重写。照抄这些句子等于把别处的东西搬进来。

**① 主语** —— 每个分句问「谁／什么在做这件事」，答不出来就把它写出来。

「V 的」当主语是合法中文（`路过的都绕着走`）。要留意的是**同一句里主语换了人**，
那时第二个主语要写出来。

- ✅ `端着走的盘沿会响一声。端得最稳那个走得最慢。`
- ❌ `摊主把货挂上去了，走过要低头拨开` → ✅ `摊主把货挂上去了，走过的人要低头拨开`
- ❌ `遮身的术法一踏上琉璃台就散` → ✅ `踏上琉璃台的人，遮身的术法当场就散`（术法不会走路）

**动词带不带得动这个宾语，也在这一条里查**：

- ❌ `星沙被站得不再流动` → ✅ `常年有人站着的白玉，底下的星沙不再流动`（`站` 不带宾语）
- ❌ `一座门开出来三四个人` → ✅ `一座门里走出三四个人`（门不「开出」人）

**② 量词** —— 把量词换成具体数字念一遍，站得住就对。

- 现实里数得出刻度的都好用：寸 · 步 · 级 · 圈 · 道 · 层 · 格。
- 「档」「度」用在真有档位刻度的东西上：灯的亮度、水的温度。
- ✅ `踩下去陷半寸` · ✅ `水镜比别的亮一档` · ✅ `丝跟着心跳一紧一松`

**③ 念出来** —— 出声念一遍，顺就对。舌头打结、需要回读的重写。

一个分句里 `的／得／地` 出现两次以上时，拆开写。
**相邻两词撞出第三个词**时也要改（`转播`＋`放送部` 撞出「播放」）。

- ✅ `举着手机那个用一只手扶住她的腰`
- ❌ `干了收紧到得拿剪子才取` → ✅ `干了收紧，要取得拿剪子`

**④ 一读到底** —— 一次读懂，不回头。长定语套长定语时**拆成两句**。

**⑤ 单读** —— 这句只有一种读法。`够`（足以／伸手取）这类两读词，换成说得死的写法。

- ✅ `外头的人按上去也觉出那一下，跟着缩肩膀`
- ❌ `讲赢了摊主认账` → ✅ `讲下来的价摊主当场就认`（前者可读成「讲赢了摊主／认账」）
- ❌ `喊的人名与要她来干什么` → ✅ `喊出的名字与要她来干什么`（前者可读成「喊的人／名」）

**⑥ 同真** —— 前半句与后半句能同时成立。判据是**物理上能否共存**。

- ✅ `云看着是实的，踩下去却托不住`（`热闹但不吵`／`亮但不刺眼` 这类对举是正常的）
- ❌ `两人背对背坐下，同时往对方腋下与腰侧使劲` → ✅ `两人背对背坐下，反手替对方搓背，搓到腰侧与肩窝`
  （背对背时手够不到对方腋下。**摆位与动作要过一遍手脚能不能到**）

### 5.9 变着写

**全库 112 份是连着写成的，同一批构式反复出现。这些不是禁词，是提醒你换个写法。**
判据：**同一份里出现两次以上就换掉一处。**

| 用惯了的 | 换成 |
| :--- | :--- |
| 「那个」指人 | 她／那人／补出身份（`端碟的`／`排在前头那位`）。**一份 ≤2 处，不连着两条都用** |
| 「最X那N」 | 直接给它名字，或写它在哪儿。一份 ≤3 处 |
| 一层压一层／压了好几层 | 写它**现在**多厚、盖住了什么。一份 ≤1 处 |
| 独有物写成「历年＋磨痕＋最旧那件」 | 换活物、装置、正在用的新东西（R2 不限器物种类，别都往旧痕迹上写） |
| 彩头写成「输的替赢的把 X…」 | 换这地方自己的彩头：请一顿 · 替对方做件小事 · 交换穿一天 · 赢家点歌 · 拍张丑照贴出来 |
| 彩头后面接一句挑刺 | **写完「输的做什么」就收笔。** 要热闹就让围观的打趣 |
| 规则标题写成「进门先X」「X才算完」 | 翻成这地方的习惯（`鞋撂在门槛外`）。进出与流程类标题**一份最多一条**，且它真是本地特征时才占位（D33） |
| 「来一次记一次社团出勤」 | 写这地方**怎么**算出勤，或不写 |
| 补一句「也没人问／谁都不说」 | 删掉。前半句信息不减就说明这半句是空的 |
| 分句用「而／但／可／却」起头 | 拆成两句，或事实并置。一份 ≤1 处 |
| 破折号 | 逗号或拆句。一份 ≤1 处，真作插入语时才用 |

> **★ 不要为了换写法去读别的地点条目。** 你只看这一份——照着别份写就是在复制这批构式。

## §6 目标结构

### 6.1 文件的真实格式（先看清，别加壳）

**地点文件里只有正文，没有任何元数据。** 第一行就是 `<scene_地点名>`，最后一行是 `</scene_地点名>`。
元数据全在 `index.yaml` 的 `条目` 列表里，**保持原样**：

> **左列条数与右列均长都不构成理由去加字。** 唯一的判据是「这一条带不带新事实」。
> 最右列 `§5.6 上限` **仍然有效**，那是密度上限，与总字数无关。

**条数弹性**（D14）：地点小、性格单一的写少一条比硬凑好；内容天然丰富的多写一条也行。
**判定标准是「这一份读完，玩家会觉得这地方是独特的」，不是字数达标。**

> **★ 一条写到什么程度算完整**（与字数无关）：
> 一件东西说清**它是什么 ＋ 能拿它干什么**就够了；有余力再给一个可感的落点——
> 什么质地、谁常用它、它现在是什么状态。
>
> ❌ 空转：`蒲团席区: 十几张摆成半圆。坐着很舒服。`（后句零信息）
> ✅ 完整：`蒲团席区: 十几张摆成半圆，正对台口那三张坐面塌得最深，来晚只剩外圈。`
>
> **但「不够长」不构成加落点的理由**——补不出新事实就在句号处收笔（R1）。
> 单条最长仍受 **§5.6** 上限管。

### 6.3 各字段的种类菜单（尽量覆盖，凑不出来就不凑）

**主要景观**（5–6）：一眼记住的大件 / 会动的或有生命的（水、云、花、鸟、光）/ 能上去或进去的。
尽量有一条是**从远处或外面就能看见的**——让 AI 能写「接近这个地方」的过程。

**固定设施**（8）：主功能设施 / 辅助（更衣、储物、清洁）/ 休息位 / 吃喝或消耗品供给 /
记录展示位（告示板、榜单、留影处）/ **边角位**（工具间、后门、杂物角）。
**每条＝名字 + 能拿它干什么**，只有名字 AI 用不上。
尽量有一条是**有点旧、有点坏、或被用出痕迹的**——一件旧东西比五件新东西更像真地方。

**独有物**（1）：提到这地方，玩家第一个想起来的那件东西。器物 / 活物（植物、动物）/ 装置 /
痕迹（前人留下的）。**不要求全库唯一，要求在这一份里够醒目。**

**日常景象**（6–8）：主事（大家主要在干的） / 顺带的社交 / 身体与衣着的细节 /
边缘角落在发生什么 / **少数人在干别的**。
最后一条尤其重要——现在通病是全场同时做同一件事，读起来像集体活动通知。

**主要功能**（5）：**前四条的小标题必须直接用 §4.1 的词表原名**（不是「取自」某类的自创名），
**第五条是自发用途，小标题自由起名**——人们自己玩出来的、当初没打算给它的用途。

```yaml
主要功能:
  - 汤泉净体: ...        # ← 词表原名，照抄
  - 闲谈八卦: ...        # ← 词表原名，照抄
  - 亲密独处: ...        # ← 词表原名，照抄
  - 修行课业: ...        # ← 词表原名，照抄
  - 赶作业与打听: ...    # ← 只有这一条自由起名
```

**为什么卡这么死**：词表存在的唯一理由是 **D8 动词映射**——种子表 `c` 的短标签要能被 L3
渲染成动作。旧库 390 条去重 367 种就是每份自创新名的结果，映射根本做不了。
所以 `采买交易` 不许写成「学园采购」「补给站」，`修行课业` 不许写成「社团活动基地」
「家政课教室」「考前冲刺」——**同一件事只能有一个名字**，正文里再写它在这地方的具体样子。
挑哪四类由地点定，**能挑满就挑满，凑不出四类写三类也行**（D14）；末位那条自发用途
是区分度的主要承载，最贴合 §5.1。

**区域特有规则**（5）：类型取自 §4.2 六类，每条写**这地方独有的规矩**（D33）。
不硬凑后果；「怎么进／怎么退／怎么算完」一份最多一条。
**小标题写描述名，不写类型名**——「端上来的不写名字」「台上说不出假话」，
不写「公开令」「禁法令」。六类是**归类用的**（自检时核覆盖面），不是标题原文。
理由：种子表 `u` 要的是「这条规则是什么」的短标签（§9），类型名传不了信息。
**这一条与 `主要功能` 正好相反**——那边必须照抄词表原名，因为 `c` 要做动词映射（D8）。

**隐秘要素**（4）：一处冷门角落（存在但没几个人去）/ 一件被误用的东西（原本干别的）/
一个只有老手知道的时机或手法（几点来、按哪里、踩哪块）。
**都必须是能被直接撞见的真事**，不是解谜进度。尽量有一条挂在已列出的固定设施上。

**招牌玩法**（1）：三行写完——怎么玩 / 怎么算输赢 / 彩头是什么。**必须写成自发玩出来的**，不是官方赛事。
彩头走「愿赌服输」：请一顿 / 替对方做件小事 / 输家当一天跟班（自愿）/ 拍张丑照贴出来 /
赢家点歌 / 交换穿一天的衣服。

**常见人群 + 人流规模**：一行「什么人 + 通常在干什么 + 什么调子」，可以混杂。
人流规模三档 **冷清 / 常有人 / 热闹**——直接告诉 AI 该摆几个人（但仍守同屏 2–4 人）。

### 6.4 随机事件（8–10 条，唯一允许打样的字段）

**每条＝一个刚开始、需要人回应的小状况**，不是已经演完的结果。
**每条一两句、≤85 字、≤4 分句，写成引子就收**——完整多分支场面由那 5 份专属事件簿负责
（§6.1.5），在这里重写一遍只是挤占上下文。**写到「有人愣住了」就停笔，不写她怎么回应、
不写事情怎么了结。** 这是全库单条最长的字段（§5.6），也**只有这个字段允许写人物反应**。

**收笔的位置**（下面两对是**参考，不许照抄**）：

- ❌ `特写正落在她身上不动。前排跟着鼓掌，她按住裙子接着往下跳。`
  → ✅ `特写正落在她身上不动。前排跟着鼓起掌来。`
- ❌ `把水递给刚下台的，两个人蹲在同一级台阶上分着喝完。`
  → ✅ `把水递给刚下台的，两个人蹲在同一级台阶上。`

尽量分散在这几种里：

| 种类 | 写什么 |
|---|---|
| **小意外** | 物件坏了、衣物出状况、东西掉了、拿错了 |
| **起争执** | 两人为小事较劲，需要第三方裁决或围观下注 |
| **撞见** | 无意间看到别人的私密一幕，双方都愣住 |
| **邀约** | 有人主动搭话、拉人入局、递东西过来 |
| **集体起兴** | 一群人临时起意搞个赌局／比赛／活动 |
| **环境异变** | 灵气、天候、阵法让场地本身变了样（**这条可以无人参与，纯写景**） |

**尽量有一条是甜的、没有冲突的**——被塞一颗糖、靠着打盹、伞往你这边倾、凉了的茶被换成热的。
按 §5.3，甜的不必和情欲分开写。

**失手的人被哄不被罚**：任何出丑的事件，落点都在「大家笑着帮她」——这是叙事指南
「安全社死」的落地写法。

### 6.5 时段景象四相（D7）

**日常景象＝这里永远是这样。时段景象＝这个时段才这样（增量）。**
**不许复述日常景象**，只在真有变化时写；没变化就写一句「和白天没两样，只是人更少」也行。

| 反例 | 正例 |
|---|---|
| 日常：泉水蒸腾，随时有人泡着聊天<br>晨：晨光中泉水蒸腾，仙宫女子泡着聊天 | 日常：泉水蒸腾，随时有人泡着聊天<br>晨：起雾最重的时候，隔两步看不清对面是谁，认人全靠声音 |

性格建议（非硬规定）：**晨**人少、水汽露水斜光、刚醒的松散、赶时间的、补作业的；
**昼**人最多、正事都在这时发生、社团与课业；**昏**金红光、收工换场、约人的、聚餐前的等待；
**夜**安静下来、私密、灯与月、卧谈与独处、门禁与偷溜。

### 6.6 内容层面的加分项（用户已采纳的五项）

1. **地点内的位置差**——点出 2–3 个**有社会含义的具体位置**：窗边座、最里侧那排柜子、
   看台最高处、靠门口的位置。不开「内部分区」字段，但 AI 立刻有了走位选择。
2. **两个群体的对照**——同一空间里**学姐 vs 学妹**（或老手 vs 新人）的不同行为方式。
   这是这个世界最强的喜剧引擎，几乎每份都能用。
3. **松弛感留白**——至少一处**有人什么正事都没干**（发呆、晒太阳、趴桌上、躺平部的在躺）。
   乌托邦的质感来自没人在赶时间。
4. **动物与活物**（非必须，按地点特色）——猫、鸟、灵鹤、灵蝶、池鱼、爬到脚边的什么。
   零风险的可爱来源，也顺手满足全女性约束。
5. **环境三槽具体化**——气味／声音／触感照 §4.3 的词源写实。

**来历**（可写可不写，按地点特点）：这地方本来是干什么的、后来怎么变成现在这样。
写进「位置」或某条景观里，一句即可。**不规定死，也不规定写法**——有的地点写来历好，
有的地点写发展过程好，有的干脆不写更干净。

### 6.7 通道型地点（`辖属` 末尾写 `通道` 的那些）

天阶、长廊、玉桥、云梯、街道这类，**过程比目的地重要**。不分档、字数目标一样，靠这三处加厚：

- **时段景象是主力**——通道的性格几乎全由人流时段决定（上课前 vs 放学后是两个地方）。
- **随机事件写成擦肩而过的小插曲**——帮人捡东西、被叫住、堵在中间、迎面撞上。
- **固定设施写路边小件**——长椅、卖水的摊子、告示板、避雨的凹处、被摸亮的栏杆。

## §9 种子表同步口径（R3 硬要求）

> 流程本身见 **§0**，这里只讲种子表 `src/前端悬浮球V1/lib/world/map-seed.data.js`
> 那一行**每个字段怎么填**。

`e`/`f`/`u`/`c` 是**从 YAML 压出来的短标签**，YAML 一重写它们就全部过期。
**这四个字段涉及别处识别，改了正文不同步等于埋一个不报错的坑。** 每份写完逐字段核一遍：

| 字段 | 怎么同步 |
|---|---|
| `n` | 全名。与文件名／`地点名称`／`<scene_X>`／`w` 后半 **五处同名** |
| `s` | 节点短名 2–5 字，不必动除非改名 |
| `r` / `a` | 辖区键 / 层位（ground·float·high·under·edge），照正文 `辖属` 那行与 §7 |
| `t` | hub / main / sub，**不是分档**，只决定地图节点大小，**不动** |
| `e` | 一句环境定场，由**新的**「位置 + 主要景观」压出，**≤40 字**，不抄环境六槽长文 |
| `f` / `u` / `c` | 固定设施 / 特有规则 / 主要功能的**短标签**，照新 YAML 重列。`c` 对应 `主要功能` 五个标题 |
| `w` | `[地点]NNN名称`，仅改名时同步 |
| `k` | 别名里最顺口的一个，**≤4 字，是绰号不是描述短语** |

**动词映射（D8）也在这里落**：`u`/`c` 的短标签要能被 L3 渲染成动作，别写成长句。
种子表动过就跑 `tsc --noEmit`（**0 容忍**）。
**地点名一律不改**（`n`/`w`/文件名／`地点名称`／`<scene_X>` 五处保持现状），
所以 `n`/`w`/`s` 通常不动。

## §10 地点台账（防撞车用）

**用途**：写新地点前扫一眼这张表，避免和已完成的地点**完全重复**。

**判定标准只有一条**：**不允许完全重复**。
重复的**元素**是允许的、也是必然的（丝袜、突击检查、社团、汤泉会反复出现，
112 份里撞元素不可避免，而且玩家一次只看到一份，撞了也无妨）。
不允许的是**整份地点没有自己的东西**——
**独有物 + 招牌玩法 + 自发用途**这三样**合起来**要让人认出「这是那个地方」。
**单看某一样不要求全库唯一**（§6.3），要求的是**这一组搭配是它自己的**。

**写法**：每写完一份，追加一行。一句话里要能看出**这地方是干什么的 + 它独有的那样东西**。
**这张表只存在于本文档，地点条目内不写任何「一句话简介」字段。**

**长度硬线（D29）**：**≈80 字，一句话，两个分句**——「是什么地方 ＋ 独有物」。
**不写**改动清单、不写「保留了什么／去掉了什么」、不写烈度说明、不写招牌玩法的规则细则。
台账只用来防撞车，过程记录不属于这里。

**已有的行不动。** 若哪一份的独有物换了，那一行的「独有物是…」后半句要跟着改，格式照旧，
第一分句（是什么地方）不动。**这半句最容易漏**——正文换了物件而台账还指着旧的，
防撞车就失效了，而且不报错。
