# 此间天地 · 悬浮球使用文档

这是一份给玩家的使用说明。开发/架构说明见同目录 [README.md](README.md),开发约定见 [PROGRESS.md](PROGRESS.md)。

「此间天地」是一个挂在酒馆（SillyTavern）页面上的悬浮球助手。它帮你把角色卡里那些藏在变量里的信息（谁在场、心情怎样、穿了什么、有哪些物品技能、现在几点天气如何）变成一块好看又能点的状态栏；还内置一整台「平板电脑」，里面有微信、微博、直播、论坛、世界演化等 20 个小应用，让你在剧情之外也能和这个世界互动。

---

## 一、怎么装进酒馆

这个助手是一段前端脚本，需要你手动导入酒馆（作者无法替你导入）。

1. 打开酒馆，进入**酒馆助手（JS-Slash-Runner）**的「前端界面 / 脚本」管理处。
2. 新建一个脚本，把打包好的产物 `dist/前端悬浮球V1/index.js` 的内容贴进去；或用远程导入一行：

   ```js
   import 'https://testingcf.jsdelivr.net/gh/wqiansu/qiyue_cjtd_qianduan@main/dist/%E5%89%8D%E7%AB%AF%E6%82%AC%E6%B5%AE%E7%90%83V1/index.js';
   ```
3. 保存并启用。页面上出现一颗**悬浮球**就说明装好了。

> 换了新版本、或作者更新后，重新导入 / 刷新一次即可。

## 二、悬浮球

- **点一下**：展开状态栏窗口。
- **拖动**：按住球拖到任意位置，位置会记住。
- **悬停**：鼠标停在球上会弹出「世界速览卡」，一眼看到当前世界信息 + 主角状态 + 在场角色（点角色名可直接看详情）；球下方还会滑出一个「世界」卫星按钮，点它直接进平板。
- **右上角小红点**：表示有「变量变化」等着你审核（见下）。

窗口顶部窄条可以拖动移动、点按钮**最大化**或**收起为球**；窗口四边和四角可**拖拽缩放**。

## 三、状态栏窗口

展开后从上到下大致是：

### 顶栏

- **标题「此间天地」**：点它可折叠/展开主体内容。
- **一排工具按钮**：
  - 地点总览 / 事件总览 / DLC补充 / 储藏间 —— 管理世界书里的地点、事件、附加设定和随身物资（见「世界书资产」）。
  - 变量审核（铃铛）—— 打开审核抽屉，逐条同意/拒绝 AI 对变量的改动，也能看历史快照。
  - 世界（地球）—— 打开平板世界套件。
  - 菜单（三横线）—— 系统 / 工具 / 设置：编辑模式、刷新、世界书识别、AI 总结注入、API 设置、外观设置、初始化管理、提示词编辑、激活监控。
- **右侧**：NPC 网格列数切换（1/2/3）、在场/全部筛选、姓名或身份搜索框，以及当前**日期 / 时间 / 天气**。

### 主体

- **左侧 · 主角**：头像（可上传）、名字、金钱、位置、姿态动作、身体状态、当前状态方块、当前穿着；还有背包 / 技能两个迷你入口（悬停看全部，点开管理）。
- **右侧 · 在场角色（NPC）**：卡片网格，在场的排前面。点卡片看该角色的完整详情（属性、状态、穿着、物品、技能、亲密记录等），卡片有轻微 3D 倾斜效果。

### 编辑模式

菜单里点「编辑模式」后，状态栏上的字段变成可直接改的输入框，方块上出现「新增状态 / 新增衣物」等按钮。你的改动会保存回角色卡变量，并进入「变量审核」等你确认。

## 四、变量审核

AI 每次输出后可能改动角色变量（比如好感 +5、换了衣服）。这些改动会先进**审核队列**（铃铛小红点提示），你可以：

- 逐条 ✓ 同意 / ✗ 拒绝，或一键全部同意 / 全部拒绝；
- 点「修改」微调后再采纳；
- 切到「快照」标签，把变量恢复到某个历史时点。

这样 AI 乱改变量时你能拦下来，不至于把存档改花。

## 五、世界书资产（地点 / 事件 / DLC / 储藏间）

顶栏那几个按钮管理的是**写进角色卡世界书**的常驻设定，分三层：实时卡片 ⟷ 初始卡片 ⟷ 世界书条目。

- **地点 / 事件 / DLC**：登记后可绑定世界书条目，需要时注入正文，让 AI 知道「你去了哪、开启了什么事件、启用了哪些补充设定」。
- **储藏间**：物品 / 技能 / 状态 / 衣物的仓库，可打标签、收藏、批量配发到主角或 NPC 身上。

「初始化管理」面板能看数据总览、校验格式、健康自检、备份恢复 / 恢复出厂。

## 六、世界套件（平板）

点顶栏「世界」按钮（或悬浮球旁的卫星按钮），屏幕中央会浮出一台平板，桌面上是一排 app 图标。这是剧情之外的「第二块屏幕」，每个 app 都用 AI 生成契合当前世界观和剧情的内容。

#### 通讯 / 社交

- **微信**：单聊 + 群聊，支持引用、撤回、拍一拍、转账红包、语音、位置、[内心] 等富交互，四个 tab（微信 / 通讯录 / 朋友圈 / 我）。
- **微博**：网感信息流、楼中楼、热搜、IP 属地，可发博、转发到微信。
- **世界论坛**：匿名民间舆论场，马甲、盖楼对线、造梗、瓜的生命周期、投票悬赏连载，还有赛事 / 报纸 / 榜单 / 问答等板块类型。
- **最右**：抽象匿名搞笑社区，神评 / 钓鱼楼 / 表情包 / 沙雕视频。
- **通话**：拨号→接通→挂断，逐句口语式对话。

#### 直播 / 影音

- **糖心直播**：PC 直播站，弹幕 / 点单 / 连麦 PK / 主播主页 / 榜单 / 好感度。
- **B站**：分区瀑布流、播放页飞弹幕、三连、UP 动态、玩家投稿。
- **喜马拉雅**：纯音频听书电台，常驻底部播放条，哄睡 / ASMR / 连麦热线。
- **小红书**：笔记瀑布流、博主主页、转发微信。

#### 生活 / 交易

- **淘宝**：服装 / 成人 / 特产多品类，钱包流水、物流推微信、直播、退款闭环。
- **美团**：外卖 + 投喂、骑手对话、团购券、霸王餐抽奖，一次生成下单到送达全程。
- **饭饭·探店点评**：仙宫版大众点评，店铺 / 评价 / 笔记 / 榜单 + 找饭搭子。
- **浏览器**：资讯流 / 搜索 / 网址宫格 / 热搜 / 网页阅读器 AI 总结追问。

#### 创作 / 记录

- **小剧场**：60 个剧本预设，导演 / 沉浸双模式，Cut 重拍分支，把幻想转成微信吐槽。
- **日历**：月历 / 周视图 / 纪事流 / 节日纪元，接世界钟。
- **日记**：纸感书页、心情系统、私密锁、AI 代笔续写。
- **工作台**：通用 AI 造物机，21 类内置模板（物品 / 技能 / NPC / 事件 / 场景…），每类的字段可增删改，产物直接塞进输入框。

#### 世界演化

- **世界演化**：在后台推演「主角镜头之外同时在发生的事」—— 角色线 / 世界背景 / 世界态（仙宫后台、打榜、社团、八卦、修罗场）/ 地点。可按楼层自动推进、写进编年史。

#### 设置 / 记忆

- **设置**：全局开关（互动人物性别、图片描述字数、桌面主题、悬浮球皮肤、写手人格、全局急停）、独立 API 管理、写作质感块。
- **记忆**：角色记忆池，按角色跨 app 共享「关键设定 / 长期 / 近期」三层记忆。

### 每个 app 的设置里能调什么

进任意 app → 设置，通常都有：读几楼正文、**注入世界书条目到本 app**（复选）、**把 app 内容回写角色卡世界书**、功能提示词（含破限，可编辑 / 恢复默认）、API 额度、记忆管理、清空数据、每 N 楼自动触发，以及各 app 专属项。

## 七、配图（可选）

app 里的图片默认是文字占位。若你在世界「设置」里配好了本地 ComfyUI（文生图后端），app 就会把画面描述转成图。连不上或没配置时自动降级为文字，绝不卡住流程。

## 八、常见问题

**状态栏一片空白 / 读不到变量？**
先确认当前角色卡是基于 MVU 变量的、且已经开始对话生成过变量。可点菜单「刷新」重新读一次；实在没有变量数据时状态栏会显示「暂无」。

**明明装好了，某天突然报错、悬浮球不出来了？**
这类前端脚本依赖一些按需从网络加载的库。若你的脚本内容没动过却突然报错，多半是某个外部库的线上版本变动导致，和你的操作无关 —— 找作者更新一版通常就好。

**AI 把变量改乱了？**
用顶栏铃铛的「变量审核」拒绝那次改动，或到「快照」里恢复到之前的状态。

**数据存在哪、会不会丢？**
状态栏和各 app 的数据存在浏览器本地（localStorage），跟着这台设备 / 这个浏览器走。「初始化管理」和世界「设置」里都有备份 / 导出，换设备或清缓存前记得导出。

**能在手机上用吗？**
这套界面是**按电脑（PC）端设计**的，没有做手机 / 响应式适配，建议在电脑上使用。

**平板里的弹窗点不动 / 位置不对？**
先关掉再重新打开该 app；仍异常就刷新一次页面。
