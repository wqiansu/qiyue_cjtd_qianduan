# 图片净化工作室

批量清理 ComfyUI(秋叶整合包)生成图里嵌入的完整工作流 / prompt 元数据,导出纯净图片。

ComfyUI 默认把 workflow(可达 2MB+)和 prompt 写进 PNG 的文本块里。本工具直接做**块级手术**:像素数据原样保留,只删掉承载 workflow/prompt 的文本块——真正零质量损失、极快、100% 干净,还能顺手省下约 40% 体积。

## 怎么用(三种方式)

### 1. 图形界面(推荐)
- 双击 `启动.bat`(首次会自动装依赖),或打包后双击 `dist\图片净化工作室.exe`。
- 把图片或整个文件夹**拖进左侧**,或点「添加图片 / 添加文件夹」。
- 选好右侧选项,点 **开始清理**。洗后自动复检,报告里给绿灯。

### 2. 打包成 exe(发给别人 / 免装 Python)
双击 `build.bat`,完成后在 `dist\ImageCleaner.exe`,单文件、双击即用。
(exe 内部名用 ASCII `ImageCleaner`,是为避开 cmd.exe 对中文路径的解析 bug;窗口标题仍是中文。)

### 3. 命令行(脚本化)
```bash
python cli.py 清理 D:\images            # 递归清理整个文件夹,输出到各目录 _cleaned
python cli.py 清理 a.png --suffix        # 原目录加后缀输出 a_clean.png
python cli.py 查看 a.png                 # 查看图里嵌了什么
python cli.py 导出 D:\images -o out.csv  # 导出所有图的 prompt 表
```

## 功能

**核心清理**
- 批量 + 递归子文件夹,多线程,进度可视化、可取消。
- 支持 PNG / JPG / WebP。
- **洗后自动复检**:重扫输出确认 0 残留,失败会在报告里标出。

**安全默认**
- 绝不原地覆盖:默认输出到源目录下的 `_cleaned` 子文件夹。
- 「原地覆盖」需二次确认,且会先把原图备份到 `_backup`。
- 可保留原图修改时间。
- 默认保留 ICC 色彩配置(防止广色域屏偏色),可手动关掉。

**顺手功能**
- **元数据查看器**:洗前先看图里有没有 workflow / prompt、占多大。
- **workflow 备份**:勾选后洗图前先把每张图的 workflow 存成 `.json`(存到 `_workflows`),先留资产再洗,永不丢工作流。
- **导出 Prompt 表**:把一个文件夹里所有图的「文件名 → 正/负提示词 → seed/步数/采样器/模型」导出成 CSV(Excel 直接可开),洗掉元数据前的 prompt 考古存档。

## 说明
- 极重度自定义工作流(参数全走节点连线)的 prompt 摘要可能抽不全,属正常——核心清理不受影响。
- 本工具全程本地处理,不联网、不上传任何图片。
